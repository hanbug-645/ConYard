# ConYard Backend

FastAPI service for AI integration and game generation.

## Tech Stack
- FastAPI
- Python 3.11+
- Uvicorn

## Development

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

API will be available at [http://localhost:8000](http://localhost:8000)
