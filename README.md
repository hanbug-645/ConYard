# ConYard

AI-native game development platform that democratizes game creation through natural language prompts.

## Repository Structure
```
/ConYard
  ├── /frontend      (Next.js code, package.json, Dockerfile)
  ├── /backend       (FastAPI code, requirements.txt, Dockerfile)
  └── README.md
```

## Architecture
- **Frontend**: Next.js 14+ with split-screen IDE interface
- **Backend**: FastAPI for AI service integration
- **Deployment**: Google Cloud Run with continuous deployment from GitHub
